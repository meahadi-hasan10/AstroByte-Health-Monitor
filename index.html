AI-assisted decision support

AstroAI Health Copilot

The copilot turns multiple signals into a concise explanation: what changed, why it matters, and what to monitor next. If an OpenAI API key is configured in the optional backend, the same panel can generate an LLM explanation. Without a key, it transparently uses the local explainable risk engine.

  • Summarizes telemetry without diagnosing disease
  • Highlights abnormal combinations, not just single values
  • Shows the reason behind each warning
  • Keeps a safe local fallback for offline mission scenarios

Why combine crew vitals + environmental context?

A single vital sign can look normal while the mission environment is changing. AstroByte combines astronaut-facing indicators with environmental context so the user can see trends and possible risk combinations in one place.

Wearable / crew vitals+NASA radiation context→Risk & trend engine→Clear action-oriented insight
